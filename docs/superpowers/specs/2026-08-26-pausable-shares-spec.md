# 可暂停共享与管理记录规格

## 目标

让本软件创建的共享支持“暂停但保留记录”“再次开启”和“删除记录”三个独立动作。

## 行为

- 暂停：删除 SMB 共享映射，保留软件管理元数据；不删除文件夹、文件、用户或权限。
- 再次开启：使用保留的共享名称、路径和账号信息恢复 SMB 共享，并刷新状态。
- 删除：删除 SMB 共享映射（如果存在）和软件管理元数据；绝不删除实际文件夹和文件。
- 外部共享继续使用现有关闭流程，不纳入本软件的暂停记录。
- 系统管理共享 `C$`、`ADMIN$`、`IPC$` 等继续禁止关闭。

## 本地数据

元数据保存到：

```text
C:\ProgramData\iPhone共享助手\managed-shares.json
```

每条记录只保存共享名称、绝对路径、状态、创建时间和访问权限信息；不保存 Windows 密码或文件内容。

## UI

- 已开启的本软件共享显示“暂停共享”和“删除记录”。
- 已暂停的本软件共享显示“重新开启”和“删除记录”。
- 危险操作显示确认窗口，并明确说明不会删除文件夹和文件。
- 外部共享和系统共享保持现有安全限制。
